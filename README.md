# Sheep's Nuclear Plant Decor

羊's 核电站装饰方块，适用于 Minecraft 1.20.1 / Forge 47.4.28 / Java 17。

现代工业建筑材质，覆盖共用厂房、RBMK 厂房、PWR 厂房、主控室和工程师办公室。内容范围为满格方块、半砖、台阶和 4px 薄板；不包含反应堆运行、能量、流体或辐射模拟。

当前版本 0.1.2 共 97 个注册方块物品：39 个满格、22 个半砖、18 个台阶、12 个薄板、1 个壁挂配电箱和 5 个立体设备。共使用 52 张 16×16 建筑贴图和 6 张 32×32 模型图集。

本轮新增 10 个 RBMK 建筑方块、5 个工业地板和 5 个真实模型，未参考或复制 001/002/003 模组设计。清单与防护组合见 [RBMK 堆厅扩充](docs/RBMK_EXPANSION.md)。

## 使用

移除 `mods` 目录中的旧 sheepnpp jar，再放入 `build/libs/sheepnpp-0.1.2.jar`；不要同时保留多个版本。联机时服务端和客户端均需安装本模组。全部方块位于“羊's 核电站装饰”创造标签页，也提供生存合成配方。

- 半砖支持上下与双层；双层破坏后掉落两个半砖。
- 台阶支持原版内角、外角及上下朝向。
- 薄板点击墙、地板或天花板放置；吊顶类仅贴天花板。移除支撑后薄板会掉落。
- 主控室纯白灯和纯白灯板亮度为 15，办公室暖白灯板亮度为 13。
- 壁挂配电箱按点击的墙面确定朝向，背面贴住支撑墙；支持东南西北，模型和碰撞箱同步旋转。只能贴墙放置，移除支撑后掉落，无电力功能或开门动画。
- 图屏、辐射监测箱、检修舱盖贴墙放置；仪控台和燃料通道头落地放置，按水平朝向旋转。它们均为静态装饰，不测量辐射、不接受燃料、不实际开门。

## NTM-Continuum 兼容

可选适配 [NTM-Continuum](https://github.com/Warfactory-Official/NTM-Continuum) 的 Minecraft 1.20.1 Forge 版本（`hbm`），不设 HBM 最低版本限制，无需 HBM 也能加载本模组。具体屏蔽效果取决于所装版本是否支持对应标签机制；本模组不针对 1.7.10 / 1.12.2 HBM、Fabric 或 NeoForge 版本适配。

0.1.1 删除了 `mods.toml` 中的 HBM 依赖声明。旧版使用的空版本范围仍会拒绝已安装的 HBM 1.0.5；本版本只声明 Forge/Minecraft 依赖，HBM 标签适配保留。

强化材质设置爆炸抗性并提供 HBM 对应防爆分类标签。悬停物品时，抗性大于 50 的方块显示金色“爆炸抗性: 数值”。该数值不代表对所有特殊爆炸免疫。

19 种满格墙体提供 `hbm:radiation_resistant` 标签，并显示深绿色“[辐射屏蔽]”。半砖、台阶、薄板及立体设备不标记为辐射密封墙，避免 HBM 把有缝隙的构件当作整格密封体。未安装 HBM 时，提示仍可查看，但不存在 HBM 辐射机制。

新铅衬砌块抗性 6 但能密封辐射，承重钢构抗性 1200 但不密封，上下生物屏蔽及复合屏蔽则兼具两者。HBM 标签密封没有百分比分级，名称不代表真实材料的辐射衰减率。

## 开发与校验

建筑贴图采用 16×16 RGBA，由规则生成像素规范，再由 Blockbench 编码、写入 PNG。立体模型使用 32×32 图集，编辑源见 `prototypes/`。当前范围与校验方式见 [计划书](docs/PLAN.md)。

依赖：Java 17、Python 3.10 及以上、Pillow。Gradle Wrapper 已包含在工程中。

已有依赖缓存时，执行全部静态检查与构建：

```bash
bash tools/check_release.sh
```

此脚本只校验和构建，不启动 Minecraft 服务端或客户端。首次下载构建依赖可使用计划书中的代理参数。

构建后自动检查 jar 内的加载元数据，确保没有 HBM 依赖版本检查，并确认配电箱的四向状态、28 个模型元素及 32×32 贴图均已打包。

贴图存档为 `docs/factory_textures.bbmodel`。`tools/texture_spec.py` 是贴图规则源，`tools/gen_assets.py` 是模型、配方、战利品及语言生成器，`tools/gen_tags.py` 是挖掘与 HBM 标签生成器。

运行时悬停画面、灯光效果和 HBM 实际爆炸/辐射效果仍需在游戏中自行验证；本项目按要求仅做静态校验与构建。
